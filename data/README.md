# Dataset — FPL Points Prediction

 

Dataset: Fantasy Premier League Dataset 2025-2026  

Source: Kaggle - Paolo Mazza  

Licence: CC0: Public Domain  

Version: 239  

The dataset was downloaded from Kaggle and the players CSV file was renamed to

`players_2025_26.csv`. The CSV file is not included in this repository. To reproduce the

project, download the dataset from Kaggle and place `players_2025_26.csv` in this folder.

 

## Download

 

1. Open the Kaggle dataset page: (a Kaggle account is needed.)  

   https://www.kaggle.com/datasets/meraxes10/fantasy-premier-league-dataset-2025-2026    

2. Click Download — Kaggle provides the dataset as a **.zip** file.  

3. Unzip it to get the players csv file.  

4. Rename the players csv file to `players_2025_26.csv`.  

5. Place it in this data folder. The program needs this exact path and filename:  

 

       data/players_2025_26.csv  

 

## Preparation  

 

No manual preparation of the data file is needed. Just put the downloaded file as

`data/players_2025_26.csv` in the data/ directory and all the preparation is done in the code.  

 

Do not edit the file by hand or the program may not work.  

## Note  

The dataset `players_2025_26.csv` is listed in .gitignore, so it is not pushed to the git repository. Download it as above.
